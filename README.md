# PixPDF (픽스피디에프)

> **100% 로컬 보안 보장 PDF ↔ 이미지 양방향 변환 및 페이지 편집기 (PWA 지원)**  
> 서버 업로드 없이 브라우저 내에서 안전하고 빠르게 PDF와 이미지를 상호 변환하고 편집할 수 있는 웹 애플리케이션입니다.

🌐 **웹 서비스(GitHub Pages)**: [https://SunnyAn2357.github.io/PixPDF/](https://SunnyAn2357.github.io/PixPDF/)  
📁 **오프라인 사용**: 루트의 `pixpdf.html` 파일을 인터넷 연결 없이 브라우저에서 바로 열어 사용할 수 있습니다.

---

### ✨ 핵심 기능

1. **PDF → 이미지 고해상도 분할 변환**
   - PDF의 각 페이지를 고화질 PNG, JPEG, WebP 이미지로 일괄 변환 및 ZIP 압축 다운로드
   - **PNG 배경 투명화 지원**: 이미지를 회전, 이동, 축소할 때 생기는 빈 여백과 회전 모서리를 흰색으로 덮지 않고 100% 투명하게 저장
   - 개별 페이지 선택 저장 및 고화질 직접 인쇄 지원
2. **다중 이미지 → PDF 단일 문서 병합**
   - 여러 장의 이미지 파일을 원하는 순서대로 하나의 PDF 문서로 즉시 병합
   - 드래그 앤 드롭으로 간편하게 페이지 순서 변경 및 추가/삭제
3. **직관적인 간편 페이지 편집기**
   - **용지 규격 및 방향**: A3, A4, A5, B3, B4, B5 및 세로/가로 맞춤 설정
   - **회전 및 미세 각도 조절**: 90도 회전 및 미세 슬라이더 각도 보정
   - **스케일 및 종횡비**: 확대/축소, 넓히기/좁히기
   - **위치 이동**: 상/하/좌/우 위치 이동 및 중앙 정렬
   - **색상 및 톤**: 밝기(Bright/Dark), 대비(진하게/연하게) 조절
   - **실시간 체커보드 프리뷰**: 배경 투명화 상태를 실시간 투명 격자 패턴으로 시각화 확인
4. **100% 클라이언트 사이드 로컬 처리 (Zero-Server & Offline-First)**
   - 업로드한 파일과 파싱된 데이터가 외부 서버로 절대 전송되지 않습니다.
   - 금융, 공공기관, 기업 폐쇄망 등 보안이 엄격한 환경에서도 안심하고 사용할 수 있습니다.
5. **PWA (Progressive Web App) 완벽 지원**
   - 브라우저 주소창에서 [앱 설치]를 통해 독립형 데스크톱/모바일 앱으로 설치 가능
   - Service Worker를 통한 완전 오프라인 캐싱 지원
   - 버전 업데이트 시 실시간 자동 새로고침(Auto-Update) 갱신
