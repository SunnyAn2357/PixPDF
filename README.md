# PixPDF (픽스피디에프)

> **100% 로컬 보안 보장 PDF ↔ 이미지 양방향 변환 및 페이지 편집기 (PWA 지원)**  
> 서버 업로드 없이 브라우저 내에서 안전하고 빠르게 PDF와 이미지를 상호 변환하고 편집할 수 있는 웹 애플리케이션입니다.

🌐 **웹 서비스(GitHub Pages)**: [https://SunnyAn2357.github.io/PixPDF/](https://SunnyAn2357.github.io/PixPDF/)  
📁 **오프라인 사용**: 루트의 `pixpdf.html` 파일을 인터넷 연결 없이 브라우저에서 바로 열어 사용할 수 있습니다.

---

### ✨ 핵심 기능

1. **PDF → 이미지 고해상도 분할 변환**
   - PDF의 각 페이지를 고화질 PNG, JPEG, WebP 이미지로 일괄 변환 및 ZIP 압축 다운로드
   - **PNG 배경 투명화 지원**: 이미지를 회전, 이동, 축소할 때 생기는 빈 여백과 회전 모서리를 흰색으로 덮지 않고 100% 투명하게 저장
   - 개별 페이지 선택 저장 및 고화질 직접 인쇄 지원
2. **다중 이미지 → PDF 단일 문서 병합**
   - 여러 장의 이미지 파일을 원하는 순서대로 하나의 PDF 문서로 즉시 병합
   - 드래그 앤 드롭으로 간편하게 페이지 순서 변경 및 추가/삭제
3. **용지(Paper) vs 이미지(Image) 분리 및 3개 창 일체화 편집기 (WYSIWYG)**
   - **용지(바탕 종이)**: A3, A4, A5, B3, B4, B5, 사용자 지정, 원본 규격 및 세로/가로 방향 설정, [페이지 회전] 지원
   - **이미지(내용물)**: 용지 위의 사진을 독립적으로 [이미지 회전], 확대/축소, 가로비율, 상하좌우 마우스/터치 드래그 위치 이동, 밝기/대비 조절
   - **3개 창 실시간 일체화**: 1열(썸네일), 2열(가운데 메인 뷰어), 3열(미니 프리뷰) 모두 바탕 용지 위에 이미지가 배치된 최종 출력 상태를 100% 동일하게 실시간 렌더링
4. **모바일 전용 반응형 UI 및 편의성 강화**
   - 썸네일 카드 터치 시 직관적인 전체 화면 페이지 편집기 자동 전환
   - **모바일 ✕ 닫기 및 뒤로가기/ESC 계층 분리 & 더블 탭 종료 토스트**:
     - 편집창 상단 `✕ 닫기` 터치 시 메인 워크스페이스로 즉시 안전 복귀 (앱 종료 팝업 오작동 원천 차단)
     - 하드웨어/제스처 뒤로가기 시 열려 있는 모달/편집창부터 1단계씩 역순으로 닫힘
     - **더블 탭 뒤로가기 종료 (Double Tap to Exit)**: 거추장스러운 종료 컨펌 모달 팝업 및 재시작 팝업을 완전히 제거하고, 뒤로가기(또는 ESC) 1회 터치 시 화면 하단에 가벼운 토스트 안내 후 2초 이내 한 번 더 누르면 즉시 앱이 종료되는 직관적인 모던 앱 UX 적용
5. **안전한 클라이언트 사이드 로컬 처리 (Zero-Server & Offline-First)**
   - `createImageBitmap`과 `FileReader` 기반의 메모리 누수 없는 안전한 다중 이미지 로딩
   - 업로드한 파일과 파싱된 데이터가 외부 서버로 절대 전송되지 않습니다.
   - 금융, 공공기관, 기업 폐쇄망 등 보안이 엄격한 환경에서도 안심하고 사용할 수 있습니다.
6. **PWA (Progressive Web App) 완벽 지원**
   - 브라우저 주소창에서 [앱 설치]를 통해 독립형 데스크톱/모바일 앱으로 설치 가능
   - Service Worker를 통한 완전 오프라인 캐싱 지원
   - 버전 업데이트 시 실시간 자동 새로고침(Auto-Update) 갱신

## 🚀 최신 업데이트 내역 (V2.0.0 - 1차 개편)

- **기본 용지 규격 원본 크기(`original`) 기본값 적용**:
  - 기존 A4 고정 기본값에서 파일 본연의 비율을 그대로 유지하는 `원본 크기`로 기본 용지 규격 전면 개편.
- **이미지 형태 편집 도구 고도화**:
  - 버튼 명칭 직관화: "넓히기" ➡️ **"뚱뚱"**, "좁히기" ➡️ **"홀쭉"**, "리셋" ➡️ **"1:1"**
  - **사다리꼴 변형 (대두/소두) 기능 탑재**:
    - **"대두"**: 상단(윗변) 확대 + 하단(아랫변) 축소 사다리꼴 변형.
    - **"소두"**: 하단(아랫변) 확대 + 상단(윗변) 축소 사다리꼴 변형.
    - WebGL 없이 순수 2D Canvas 60스트라이프 슬라이싱 기법을 적용하여 화면 뷰어, 썸네일, 미니 프리뷰, 최종 파일 저장(PDF/ZIP)까지 100% 동일하게 오프라인 고속 렌더링.
- **`+ 삽입` 드롭다운 메뉴 및 빈 페이지 삽입 지원**:
  - 기존 단일 파일 인풋 버튼을 삼선 스타일 드롭다운 메뉴(`+ 삽입 ▾`)로 개편.
  - **`📄 빈페이지`**: 클릭하여 작업 중인 이미지 바로 아래 위치에 현재 선택된 용지 규격 비율에 맞는 깨끗한 순백색 빈 페이지를 즉시 생성 및 삽입.
  - **`📁 파일`**: 기존처럼 원하는 위치에 PDF 또는 이미지 파일을 즉시 추가 삽입.
