# MY PDF (PixPDF) - PDF & 이미지 양방향 변환 및 편집기

> **100% 로컬 메모리 격리 기반 PDF ↔ 다중 이미지 양방향 변환 및 정밀 편집기**  
> 외부 서버 업로드 없이 업무용 PC(데스크톱 앱) 및 웹 브라우저(PWA)에서 안전하고 빠르게 PDF와 이미지를 상호 변환하고 편집할 수 있는 올인원 유틸리티입니다.

---

## 🌐 실행 및 배포 환경

1. **MY Apps 업무용 데스크톱 설치판 (`MY_PDF_Setup.exe`)**
   - **설치 경로**: `C:\Program Files\MY_ADS\MY_PDF`
   - **보안 규격**: MY Apps 디지털 서명(Windows 스마트 앱 컨트롤 통과) 및 사내 라이선스(`.ads_cert`) 인증 적용
   - **타 PC 최초 설치 안내**: 신규 PC에 설치할 때는 `Setups\배포용 인증서\` 폴더의 **`최초1회_SAC보안인증서.exe`**와 **`MYApps_보안인증서.exe`**를 먼저 1회 실행한 후 `MY_PDF_Setup.exe`를 설치하십시오.
2. **개인용 / 온라인 웹 & 모바일 PWA 버전**
   - **웹 서비스 주소**: [https://SunnyAn2357.github.io/PixPDF/](https://SunnyAn2357.github.io/PixPDF/)
   - **오프라인 단독 실행**: 루트의 `pixpdf.html` 또는 `index.html`을 브라우저에서 바로 열어 사용 가능 (MY Apps 보안인증서 의존성 0%, 100% 순수 클라이언트 구동)

## ✨ 핵심 기능 요약

1. **단일 하이브리드 워크스페이스 (PDF + 이미지 자유 혼용)**
   - PDF 문서와 여러 장의 이미지(PNG, JPG, WebP, BMP, GIF, TIFF, SVG, ICO 등)를 동시에 불러와 페이지 순서를 자유롭게 섞고 편집·병합·분할 저장할 수 있습니다.
   - 빈 페이지 삽입(`+ 삽입 ▾` → `📄 빈페이지`), 페이지 복제, 드래그 앤 드롭 정렬을 지원합니다.
2. **용지(Paper) vs 이미지(Image) 분리 및 3개 창 실시간 일체화 (WYSIWYG)**
   - **용지 설정**: 원본 크기, A3, A4, A5, B4, B5, 레터, 사용자 지정(mm) 규격 및 가로/세로 방향, 여백 설정, [페이지 회전] 지원.
   - **이미지 변환**: 용지는 고정한 채 내용물만 독립적으로 회전(90° 및 미세 각도), 확대/축소, 가로비율(뚱뚱/홀쭉), 사다리꼴(대두/소두), 4모서리 사각 투시 변환(Perspective Warp), 용지 자르기(Crop), 밝기/대비/선명도/흑백 필터 조절.
   - **3분할 일체화**: 1열(썸네일), 2열(중앙 고해상도 뷰어), 3열(미니 프리뷰) 및 최종 인쇄/저장 결과물이 100% 일치합니다.
3. **고급 레이어 오버레이 편집 (데스크톱)**
   - 용지 위에 **글상자(텍스트)**, **도형(사각형/원/직선/화살표)**, **추가 이미지(도장/서명/로고)** 레이어를 무제한 얹어 자유롭게 배치하고 스타일을 편집할 수 있습니다.
4. **고품질 출력 및 프로젝트 백업 (`.mypdf`)**
   - **`[PDF 저장]`**: 체크된 모든 페이지를 고해상도 단일 PDF 문서로 즉시 병합 저장.
   - **`[Img 저장]`**: PNG(투명 배경 지원), JPEG, WebP, BMP, TIFF, SVG, ICO 등 10종 포맷 개별 다운로드 또는 ZIP 일괄 압축 저장.
   - **`[.mypdf 프로젝트]`**: 작업 중인 레이어와 편집 상태를 그대로 파일로 백업하고 언제든 이어서 편집 가능.
